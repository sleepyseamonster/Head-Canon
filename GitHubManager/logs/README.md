# GitHub Manager Logs

This directory stores append-only repo-management logs.

Files:
- [activity.jsonl](/Users/worldbuilder/Desktop/Head%20Canon/GitHubManager/logs/activity.jsonl)
  Chronological actions taken by the GitHub manager.
- [decisions.jsonl](/Users/worldbuilder/Desktop/Head%20Canon/GitHubManager/logs/decisions.jsonl)
  Durable workflow decisions that future sessions should honor.

Rules:
- log observed state, not speculation
- keep entries short and concrete
- prefer append-only updates over rewriting history
