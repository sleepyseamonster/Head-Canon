## Additional Bug Found On May 16, 2026
User reported:
- clicking `Relaunch` did nothing

Diagnosis:
- `Relaunch` button was wired, but the relaunch implementation used a fragile `NSWorkspace` reopen path

Fix made in source:
- patched `relaunchApp()` to use `/usr/bin/open -na /Applications/HeadCanon.app`
- then terminate the current app instance after a short delay

File changed:
- [Sources/HeadCanon/App/HeadCanonModel.swift](/Users/worldbuilder/Desktop/Head%20Canon/Sources/HeadCanon/App/HeadCanonModel.swift)

Build result after fix:
- `swift build` passed on May 16, 2026
- `swift test` passed on May 16, 2026

Important limitation:
- the user must reinstall the updated build for the new relaunch code to reach `/Applications/HeadCanon.app`
